Install

Your pull request. Explained.

MergeStory turns a pull request into a short narrated video: what changed, why, and what to review. Open source, and made on your machine.

Install MergeStory Watch the film

A big pull request is hard to read. A short video does the first pass.

Today you open the diff and rebuild the author's thinking. It takes time, and a risky line is easy to miss. With MergeStory, a narrator walks you through the change, so you know where to look before you open the diff.

Reads. Tells. Checks.

Your coding agent writes the story. The engine checks it, then makes the video on your machine.

  1. Reads.

    MergeStory reads the pull request or branch and builds an evidence pack. Every fact gets an id.

  2. Tells.

    Your coding agent already knows the change, so it writes the storyboard. No agent? MergeStory builds one offline.

  3. Checks.

    The engine checks every claim and every line reference. Then a free voice reads the script, and your browser draws each frame.

No MergeStory fee. By design.

$0

$0 per video, from MergeStory1

A default run calls no paid service of its own.1 You need no account and no key for your first video. The real cost is your coding agent's usage: about 20 cents per video if you pay per token.

  • Storyboard~$0.20

    Written by the coding agent you already use. That is extra usage in your session. If you pay per token, your agent's provider bills it: we measured roughly $0.15 to $0.45 per video with a Sonnet-class agent. On a subscription plan it counts toward your usage limits.1

  • Voice$0

    Kokoro, an open English voice that runs on your own CPU. Installed once: about 400 MB, plus the voice model.

  • Rendering$0

    Your own browser draws each frame. FFmpeg encodes. In CI, it uses your CI minutes.1

  • Checks$0

    Every claim and line reference is checked on your machine.

  • SharingVaries

    Local by default, with nothing to pay. YouTube and Google Drive use your own account and storage. R2 and S3 bill you for storage and requests.1

  • A $0.25 budget per run.

    MergeStory checks its estimate before each paid model or voice call and does not make a call that would go over. It guards MergeStory's own paid calls. Your final bill can still differ.3

  • Paid services are opt-in.

    A model for the storyboard or a cloud voice is one setting each, billed by its provider. Every run reports its estimated cost2 and lists what left your machine.

Private by default.

Your code stays on your machine unless you decide otherwise.

  • No telemetry.

    MergeStory does not report what you do or what you make.

  • Nothing leaves unless you set it up.

    Nothing from your code goes anywhere until you turn on a model, a cloud voice or an upload. The only download is the free voice, once.

  • Sensitive files stay out.

    Files like .env, keys and credentials are never shown and never sent.

  • Secrets are masked.

    Secrets and e-mail addresses are masked in code, captions, narration and logs. Captures you supply are shown as they are, apart from the regions you hide.

  • Links you control.

    Private S3 links stop working after 7 days at most. Google Drive and YouTube links do not expire. Public links for a private repository are blocked unless you allow them.

  • Read-only.

    MergeStory never changes your repository or its git state.

Your coding agent already sees the change in your session. MergeStory adds no other service. Check it yourself: add --dry-run to any command and it shows the plan, the cost estimate and what would leave your machine, and renders nothing. Or read the code on GitHub and the security policy.

Know before you install

One catch: the first video takes longer.

The first English video installs the free voice once. That is about 400 MB, then the voice model, so it takes a minute or two longer. Nothing from the change is sent.

  • Do it ahead of time. Run mergestory setup kokoro, for example in CI.
  • The free voice speaks English. The offline storyboard is English only too. Other languages use a system voice, a cloud voice you turn on, or captions only.

What MergeStory is not.

  • Not a reviewer. It points to what to review. You decide.
  • Not a service. There is no account. It runs on your machine.
  • Not proof. The checks tie each line to the change. A sentence can still be wrong.
  • Not a cheerleader. Claims it cannot check are removed.

Questions before you install.

Short answers. The documentation has the rest.

Does my code leave my machine?

Not by default. The analysis, the checks, the voice and the rendering all run on your machine. There is no telemetry.

Something leaves only if you turn it on: a model that writes the storyboard, a cloud voice, or an upload. Run --dry-run to see what would leave. Your coding agent already sees the change in your session. MergeStory adds no other service.

What does it cost?

MergeStory charges nothing, and a default run calls no paid service.1 You may still pay others for your coding agent's usage (about 20 cents per video in our measurements, if you pay per token), storage, CI minutes and any model or cloud voice you turn on. If you opt in to a model for the storyboard, Claude Haiku 5.5 is estimated at under $0.01 per video for a typical change.2 Cloud voices are priced per million characters. A budget of $0.25 per run is checked before every paid call.3 See the full cost.

Can I use it without an agent?

Yes. Run mergestory generate on a pull request URL or a local branch. Without an agent, it builds the storyboard offline from the analysis. You can also use the HTTP API or the library.

Is the narration accurate?

Every narration line cites evidence from the change, and the code on screen is read from your repository. Claims nobody can check, like "all tests pass", are removed unless real test results were supplied. The checks run on your machine before rendering.

It checks claims against the change. The checks do not prove that every sentence is right: a count or a description can still be wrong. It also cannot judge whether the change is a good idea, so use the review checklist as a starting point. The video does not replace code review.

Where do the videos go?

They stay on your machine. You get an MP4 video, captions (VTT and SRT), a poster image and a local watch page. Share one when you are happy with it: YouTube, Google Drive, S3-compatible storage, or a comment on the pull request.

Can I run it in CI?

Yes. The GitHub Actions example makes a video when a maintainer adds a label to a pull request. It uploads the video to your own storage and posts one comment with the link. Read the guide.

Does it work with my git host?

Videos work with every git host: run mergestory generate . --base main --head feature/retry on a local branch. Reading a pull request by its URL and posting the comment need GitHub. MergeStory for Chrome works on GitHub too.

Notes

  1. MergeStory is open source and charges nothing. A default run calls no paid service. Other costs can still apply. Their providers bill you, not MergeStory:
    • your coding agent's own usage, if you pay for it per token. The agent reads MergeStory's instructions and evidence pack again on each step, and writes the storyboard. With a Sonnet-class agent at list prices, we measured roughly $0.20 to $0.45 per video for a fresh agent on each pull request, as in CI, and roughly $0.15 to $0.25 when the same session wrote the change. That is many times the cost of an opt-in model. See the numbers.
    • a model (--llm) or a cloud voice (--tts) that you turn on.
    • storage and delivery. Amazon S3 bills storage, requests and data transfer out. Cloudflare R2 bills storage and operations above its free tier. Google Drive uses your storage quota.
    • GitHub Actions minutes for private repositories.
    • your own machine's time, power and network, including a one-time voice download of about 400 MB, plus the voice model.
    ↩︎
  2. Prices are estimates from the providers' list prices, checked in November 2026. Providers change their prices. Your provider's bill is the final word. ↩︎
  3. The budget is per run, not per day or month. It is a safeguard, not a guarantee of your final bill. It uses the estimates in note 2 and covers only paid model and voice calls. It does not cover storage, CI minutes or your coding agent's usage. A model server or gateway on this machine or a private network counts as $0 only when no price is known for its model, built in or in pricing, even when it forwards to a paid service. A model with an unknown price is counted at the highest rate. To cap your real bill, set a spending limit or alert with each provider. ↩︎
