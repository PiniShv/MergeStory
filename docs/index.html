Every change has a story.

MergeStory turns a pull request into a short narrated video. What changed, why, and what to review.

Open source, and it runs on your machine.

Install Watch the film

"Free" in the film means MergeStory adds no charge with the default settings. Your coding agent's usage, storage and CI minutes can still cost money.1

Install it with one command.

Pick the way you work. Then run mergestory doctor to check your setup.

Other agents

Reads. Tells. Checks.

Your coding agent writes the story. The engine checks every claim before it draws a single frame.

  1. AnalyzerReads the pull request or branch and builds an evidence pack.
  2. StoryboardThe script. Your coding agent writes it from the evidence pack.
  3. Grounding checksEvery claim and every line reference is checked.
  4. NarrationA free voice reads the script on your machine.
  5. RendererYour browser draws each frame. FFmpeg encodes the video.
  6. PublishLocal by default. Share it only if you choose.
  1. 01

    Your agent already knows the change.

    It made the change, or it reviews it. So it writes the storyboard. Without an agent, MergeStory builds one offline from the analysis.

  2. 02

    The engine checks every claim.

    Each narration line must cite evidence from the change. Each line reference must point at real code. Claims nobody can check, like "all tests pass", are removed unless real test results were supplied.

  3. 03

    Then it renders, on your machine.

    The same input gives the same video. Code on screen is read from your repository. Simulated visuals are labelled.

$0. By design.

A default run calls no paid service of its own.1 No account. No key for your first video.

$0

$0 per video, from MergeStory1

  • StoryboardVaries

    Written by the coding agent you already use. That is extra usage in your session. If you pay per token, your agent's provider bills it.1

  • Voice$0

    Kokoro, an open English voice that runs on your own CPU. Installed once: about 400 MB, plus the voice model.

  • Rendering$0

    Your own browser draws each frame. FFmpeg encodes. In CI, it uses your CI minutes.1

  • Checks$0

    Every claim and line reference is checked on your machine.

  • SharingVaries

    Local by default, with nothing to pay. YouTube and Google Drive use your own account and storage. R2 and S3 bill you for storage and requests.1

Why it is so cheap.

  • The agent

    The agent already knows the change.

    Your coding agent made or reviewed the change, so it writes the storyboard. No second model reads the whole change again. Writing it is extra usage in your session: the agent reads MergeStory's instructions and evidence pack, often more than 10,000 tokens. If you pay per token, your agent's provider bills that usage.1

  • Local software

    Everything else is ordinary.

    An open voice model on your CPU, the browser you already have, and FFmpeg. No render farm. No cloud GPU.

  • Opt-in

    Paid services are one setting each.

    You can let a model write the storyboard, or use a cloud voice. The default is the cheapest capable model.

  • Honest

    Every run reports its estimated cost.

    It counts MergeStory's own paid calls, from list prices.2 It also lists every outbound transfer: the host, the purpose and the size.

When you want more.

Both are opt-in, and the provider bills your own account. These are estimates from list prices, checked in November 2026.2 You can override them in the config.

Opt-in prices
  • --llm anthropicClaude Haiku 5.5 storyboard: estimated under $0.01 per video for a typical change ($0.10 per million input tokens, $0.50 per million output tokens)
  • --tts openaiOpenAI gpt-4o-mini-tts: $18 per million characters, about $0.015 per minute of speech
  • --tts elevenlabsElevenLabs Flash: $40 per million characters
  • --tts elevenlabsElevenLabs v3 and Multilingual v2: $80 per million characters

A 2-minute narration is roughly 1,600 characters.

A $0.25 budget per run, checked before every paid call.

MergeStory checks its estimate before each paid model or voice call and does not make a call that would go over. A model with an unknown price is counted at the highest rate. It is a safeguard, not a guarantee of your final bill.3 Change it with --budget.

How the cost works  ›

Three steps.

Or ask your agent: "explain this pull request as a video".

  1. Install it.

    npm install -g mergestory

  2. Check your setup.

    mergestory doctor lists anything missing, with a fix for each.

  3. Make a video.

    mergestory generate <pull request URL>

You need Node.js 22.12 or newer, git, FFmpeg, and Google Chrome or another Chromium browser. No pull request? Run mergestory generate . --base main --head feature/retry on a local branch. It works with every git host. Add --dry-run to see the plan, the cost estimate and what would leave your machine, without rendering.

Quality presets: draft is 1280x720 at 24 fps. Standard, the default, is 1920x1080 at 30 fps. High is 1920x1080 at 60 fps.

Private by default.

Your code stays on your machine unless you decide otherwise.

  • Telemetry

    No telemetry.

    MergeStory does not report what you do or what you make.

  • Your code

    Nothing leaves unless you set it up.

    Nothing from your code or the change goes anywhere until you turn on a model, a cloud voice or an upload. The only download is the free voice, once. It sends nothing from the change.

  • Sensitive files

    Never shown, never sent.

    Files like .env, keys and credentials are left out of every video.

  • Secrets

    Masked everywhere.

    Secrets and e-mail addresses are masked in every frame, caption and log.

  • Links

    Links you control.

    Private S3 links stop working after 7 days at most. Google Drive and YouTube links do not expire. Public links for a private repository are blocked unless you allow them.

  • Your repository

    Read-only.

    MergeStory never changes your repository or its git state.

Know before you install

One catch: the first video takes longer.

The first English video installs the free voice once. That is about 400 MB, then the voice model, so it takes a minute or two longer. Nothing from the change is sent.

  • Do it ahead of time. Run mergestory setup kokoro, for example in CI.
  • It needs FFmpeg and a browser. Google Chrome or another Chromium browser draws the frames.
  • The free voice speaks English. The offline storyboard is English only too.

What MergeStory is not

  • Not a reviewer. It points to what to review. You decide.
  • Not a service. There is no account. It runs on your machine.
  • Not one voice for every language. Kokoro speaks English only. Other languages use a system voice, a cloud voice you turn on, or captions only.
  • Not a cheerleader. Claims it cannot check are removed.

Questions before you install.

Short answers. The documentation has the rest.

Does my code leave my machine?

Not by default. The analysis, the checks, the voice and the rendering all run on your machine. There is no telemetry.

Something leaves only if you turn it on: a model that writes the storyboard, a cloud voice, or an upload. Run --dry-run to see what would leave. Your coding agent already sees the change in your session. MergeStory adds no other service.

What does it cost?

MergeStory charges nothing, and a default run calls no paid service.1 You may still pay others for your coding agent's usage, storage, CI minutes and any model or cloud voice you turn on. If you opt in to a model for the storyboard, Claude Haiku 5.5 is estimated at under $0.01 per video.2 Cloud voices are priced per million characters. A budget of $0.25 per run is checked before every paid call.3 See the full cost.

Which agents does it work with?

It is an Agent Skill for Claude Code, Codex, GitHub Copilot, Cursor, OpenCode, Goose, Amp, Gemini CLI, Windsurf, Kiro and Cline. See where each one reads it from.

Can I use it without an agent?

Yes. Run mergestory generate on a pull request URL or a local branch. Without an agent, it builds the storyboard offline from the analysis. You can also use the HTTP API or the library.

Where do the videos go?

They stay on your machine. You get an MP4 video, captions (VTT and SRT), a poster image and a local watch page. Share one when you are happy with it: YouTube, Google Drive, S3-compatible storage, or a comment on the pull request.

Is the narration accurate?

Every narration line cites evidence from the change, and the code on screen is read from your repository. Claims nobody can check, like "all tests pass", are removed unless real test results were supplied. The checks run on your machine before rendering.

It checks claims against the change. It cannot judge whether the change is a good idea, so use the review checklist as a starting point.

Can I run it in CI?

Yes. The GitHub Actions example makes a video when a maintainer adds a label to a pull request. It uploads the video to your own storage and posts one comment with the link. Read the guide.

What does it need?

Node.js 22.12 or newer, git, FFmpeg, and Google Chrome or another Chromium browser. The first English video also installs the free voice once, about 400 MB plus the voice model. Run mergestory doctor to check.

Notes

  1. MergeStory is open source and charges nothing. A default run calls no paid service. Other costs can still apply. Their providers bill you, not MergeStory:
    • your coding agent's own usage, if you pay for it per token. The agent reads MergeStory's instructions and evidence pack, often more than 10,000 tokens, and writes the storyboard. That can cost more than an opt-in model.
    • a model (--llm) or a cloud voice (--tts) that you turn on.
    • storage and delivery. Amazon S3 bills storage, requests and data transfer out. Cloudflare R2 bills storage and operations above its free tier. Google Drive uses your storage quota.
    • GitHub Actions minutes for private repositories.
    • your own machine's time, power and network, including a one-time voice download of about 400 MB, plus the voice model.
    ↩︎
  2. Prices are estimates from the providers' list prices, checked in November 2026. Providers change their prices. Your provider's bill is the final word. ↩︎
  3. The budget is per run, not per day or month. It is a safeguard, not a guarantee of your final bill. It uses the estimates in note 2 and covers only paid model and voice calls. It does not cover storage, CI minutes or your coding agent's usage. A model server or gateway on this machine or a private network counts as $0 only when no price is known for its model, built in or in pricing, even when it forwards to a paid service. To cap your real bill, set a spending limit or alert with each provider. ↩︎
